Hermes Agent standalone plugin · v0.1.0

hermes-jev-curator

A typed semantic-governance layer around Hermes Curator: deterministic candidates, Jev relation judgments, direct-edge plans, an offline mutation guard, and an explicitly gated archive-only apply path. Hermes keeps ownership of skills, snapshots, provenance, and the mutation ledger.

Hermes integration seams

Everything rides stock plugin APIs; there are no core patches or monkeypatches.

Manifest

kind: standalone, manifest v2, one tool and two hooks. Doctor/validate compare declarations with a recording execution of register(ctx).

Skills toolset

jev_skill_relations joins toolset="skills", so the curator fork can request typed relations without gaining a mutation surface.

System prompt

A callable prompt section renders only when session_info.platform == "curator". CLI, gateway, and unrelated agents receive nothing.

Hooks

on_skill_lifecycle records bounded facts. pre_tool_call guards only background-review skill_manage writes in guard/apply modes, locally and without network.

Commands

hermes jev-curator … uses the CLI subtree; /jev-curator is async and dry-only. Chat cannot pass the apply gate.

Config

ctx.get_config reads plugins.entries.jev-curator.settings.* on every call. Invalid modes fall back to observe, never apply.

Core reads

skill_usage, skill_utils, cron references, and eligibility predicates define the inventory and protected population. The plugin does not copy core allowlists.

Core writes

ctx.dispatch_tool("skill_manage", …) performs archival under background_review provenance. Snapshot, ledger, archive, restore, and rollback remain Hermes-owned.

Credentials

Runtime provider resolution and active-profile dotenv lookup are reused. Credentials are accepted only when their bound origin matches the configured route.

State

Profile-local atomic state under $HERMES_HOME/jev-curator; bounded/redacted audit and reports; no writes to core-owned .usage.json or .curator_state.

Runtime paths

One pipeline, three operational postures.

Observe path

Inventory + candidatesDeterministic and local.
Consent gateNo request unless mode is not off and content egress is explicitly enabled.
Typed Jev judgmentMalformed, truncated, or nonfinite evidence fails closed.
Graph + reportPlans may be produced; skills remain byte-identical.

Guard path

Validated plans installedExact digests, canonical, member, and direct edge.
pre_tool_call firesOnly for background-review skill_manage.
Local inventory re-checkNo network call inside the hook.
Block by defaultOnly an exact authorized absorption passes. Content edits and stale hashes are refused.

Apply path

Terminal-only authorizationmode: apply + explicit run --apply.
Evidence + digest gatesFresh complete direct edges; unprotected targets; no staged replay.
Hermes snapshotFailure stops before mutation.
Archive through skill_manageRequires _archived: true, then verifies source disappearance and unchanged canonical.

Safety invariants

The architecture is deliberately asymmetric: easy to observe, hard to mutate.

Read-only defaultObserve mode is the fallback for missing, malformed, or unknown mode values.
Explicit egress consentRedacted, bounded skill content leaves the machine only after a dedicated boolean opt-in.
Typed evidenceEvery answer is validated; missing keys, invalid probability sets, NaN, and truncation cannot authorize.
Hash bindingCache keys, graph edges, plans, guard checks, and apply checks pin package content digests.
Direct edges onlyNo transitive merge authorization. Every absorbed member needs its own canonical relation.
Core owns protectionEligibility, provenance, references, snapshots, ledger, archive, restore, and rollback come from Hermes.
No hard deleteThe only destructive action is a recoverable archive through core's background-review path.
Fail-closed guardStale plans, ambiguous names, mismatched paths, protected artifacts, content edits, and hook errors block.
Measured boundary: wiring and safety behavior are verified offline. Live Jev model quality and apply behavior against a production skill library remain intentionally unclaimed.
